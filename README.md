# Space Shooter Game
I used PyGame in this project and was inspired from the space-shooter games. 
## Features
* Restart mechanism
* Explosion effect and Scoreboard
* Dynamic enemy spawn system with a maximum of 5 enemies at a time
* Frame-independent movement and shooting cooldown of 0.25 seconds
## Controls
- **WASD**: Move the plane
- **Space**: Fire
- **R key**: Restart (when game is over)
## Setup and Running
**Install the required library**
```bash
pip install pygame
```
**Start the game***
```bash
python plane1.py
```
